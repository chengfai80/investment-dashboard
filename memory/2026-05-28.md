
## 2026-05-28 — Financial Tracker mobile blank-screen investigation
- Root cause for the blank-screen APK appears to involve Expo Updates startup config; logcat showed: `The expo-updates system is disabled due to an invalid configuration. Ensure a valid URL is supplied.`
- The Android launcher icon issue was due to the native `android/` project using stale generated resources; regenerating the native Android project from Expo config fixed it.
- The app was upgraded to Expo SDK 56 with React 19 / RN 0.85 and `react-native-gesture-handler` + `expo-system-ui` added for Android compatibility.
- Launch-time UI hardening was added (gesture-handler root, safe area provider, error boundary, diagnostic boot screen) to make startup failures visible.
- `expo-updates` was removed from the app config and dependencies to eliminate the invalid startup path; a fresh EAS Android build was triggered from the stripped config.

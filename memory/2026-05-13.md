## Learned / Remember
- Moomoo/OpenD on the Ubuntu host listens on `127.0.0.1:11111`; the OpenClaw gateway can stay loopback-only when the app runs directly on the host.
- For the portfolio cron, the agent job must be allowed to use `exec`, and the command path should be anchored with `cd /home/chengfai/.openclaw/workspace && bash ./scripts/update_and_push_portfolio.sh` to avoid allowlist/path mismatches.
- Daily portfolio update failures can come from two different sources:
  - Moomoo/OpenD connection refused (`ECONNREFUSED`)
  - Cron execution blocked by allowlist / runtime restrictions
- Git push for `chengfai80/investment-dashboard.git` can fail when remote main has advanced; fix with `git stash -u`, `git pull --rebase origin main`, then push.
- If a stash/rebase flow makes tracked scripts appear missing, check stash contents before assuming deletion; restore from the stash if needed.
- Cron job approvals may need scope upgrades before runs can execute; after approval, rerun the job and verify run history.

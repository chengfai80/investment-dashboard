# 2026-05-30

- User has a working reference mobile app under `financial-tracker-app` and asked to compare it against the current mobile app to learn what went wrong.
- Key finding from the comparison: the current mobile app likely has an auth/API route mismatch. The working app uses `/api/auth/login` and `/api/auth/me`, while the current app uses `/auth/login` and `/auth/me`.
- The working app also has a more complete shared service layer for token storage/restore and biometric login, while the current app is cleaner at the shell level but may be calling the backend incorrectly.
- Current app is on newer Expo/React Native/React versions than the working app, so native dependency/version drift may also be contributing to breakage.

- On 2026-05-30, the mobile app build issue was narrowed down: the root `.easignore` had been too aggressive and caused EAS to upload an almost-empty archive (~80 B). Fixing the ignore rules allowed real archives (~190 MB) to upload.
- EAS build submissions then failed intermittently with `getaddrinfo EAI_AGAIN api.expo.dev`, indicating a transient DNS/network issue to Expo rather than an app bug.
- The Android preview build eventually succeeded and the app now reaches the login screen.
- The mobile client uses `EXPO_PUBLIC_API_BASE_URL` plus `/api/auth/login` and `/api/auth/me`; the Cloud Run base URL should be the service root without `/api`.
- The correct Cloud Run backend URL for this project is `https://financial-tracker-backend-1034658393263.asia-southeast1.run.app`.
- The app fallback API base was corrected to that Cloud Run URL so the APK can still work if the env var is missing.
- Backend verification showed `POST /api/auth/login` returns a token successfully when called directly, and `GET /api/auth/me` returns `401` without the bearer token, which is expected.
- The remaining action for mobile auth is to rebuild the APK after the base URL correction and ensure the Expo preview environment has `EXPO_PUBLIC_API_BASE_URL=https://financial-tracker-backend-1034658393263.asia-southeast1.run.app`.
